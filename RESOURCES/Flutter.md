# 📱 Flutter Development Resources

For students pursuing mobile development roles, this file tracks best resources for learning **Dart**, **Flutter**, State Management, and clean architecture.

---

## 📖 Recommended Books
* **"Flutter in Action"** by Eric Windmill - *Great intermediate guide.*
* **"Dart in Action"** by Chris Buckett - *Good foundation for Dart language features.*

---

## 🎥 YouTube Channels & Playlists
* 📺 **Official Flutter Channel:** [Flutter YouTube Channel](https://www.youtube.com/@FlutterDev) - *Features like "Widget of the Week" and tutorials.*
* 📺 **Rivaan Ranawat:** [Flutter Playlists](https://www.youtube.com/@RivaanRanawat) - *Full project walkthroughs (Clone apps).*
* 📺 **Net Ninja:** [Flutter For Beginners](https://www.youtube.com/playlist?list=PL4cUxeGkcC9jLYyp2Aoh6hcWuxFDX6PBJ) - *Excellent beginner playlist.*
* 📺 **Reso Coder:** [Flutter Clean Architecture](https://www.youtube.com/@Resocoder) - *Advanced architecture and state management.*

---

## 📰 Articles & Documentation
* 📄 **Official Documentation:** [flutter.dev/docs](https://docs.flutter.dev/) - *The ultimate, up-to-date resource.*
* 📄 **Flutter Gems:** [fluttergems.dev](https://fluttergems.dev/) - *Curated categorization of Flutter packages.*
* 📄 **Medium (Flutter Community):** [Flutter Community Blog](https://medium.com/flutter-community) - *Advanced design patterns and articles.*

---

## 💻 Practice Platforms
* 🏆 **Dartpad:** [dartpad.dev](https://dartpad.dev/) - *Online IDE to write and practice Dart code.*
* 🏆 **Exercism (Dart track):** [exercism.org/tracks/dart](https://exercism.org/tracks/dart) - *Coding challenges focused on Dart.*
* 🏆 **Flutter Hackathons / Git Projects:** Build personal projects and publish them on GitHub to display in your resume.
