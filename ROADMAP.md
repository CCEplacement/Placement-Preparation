# 🗺️ Placement Preparation Roadmap

This roadmap outlines the systematic preparation plan divided into structured phases. Use this document to keep track of overall community milestones. Individual student progress should be tracked in their respective folder updates.

## 🚀 Phase 1: Foundation & Warmup (Weeks 1 - 4)
*Goal: Brush up programming language fundamentals, learn to use Git/GitHub, and start daily quantitative aptitude practice.*

- [ ] **Week 01: Getting Started & Basics**
  - [ ] Git & GitHub workflow setup.
  - [ ] Time & Space Complexity analysis.
  - [ ] Basic Mathematics & Bit Manipulation.
  - [ ] Seminar: "Mastering the Git & GitHub Collaboration Flow".
- [ ] **Week 02: Core Data Structures (Arrays & Strings)**
  - [ ] Array operations, searching (Binary Search), and basic sorting.
  - [ ] Two-pointer and Sliding Window techniques.
  - [ ] String manipulation and pattern matching.
  - [ ] Seminar: "Sliding Window & Two-Pointer Strategies".
- [ ] **Week 03: Basic Linear Data Structures**
  - [ ] Recursion & Backtracking foundations.
  - [ ] Singly, Doubly, and Circular Linked Lists.
  - [ ] Stacks & Queues: Implementations and classic problems (e.g., Next Greater Element).
- [ ] **Week 04: Basic Aptitude & Logical Reasoning**
  - [ ] Percentages, Profit & Loss, Ratio & Proportion.
  - [ ] Number Series and Coding-Decoding.
  - [ ] Mock Test 1 (Aptitude & Basic DSA).

---

## 🧠 Phase 2: Core DSA & CS Concepts (Weeks 5 - 12)
*Goal: Deep dive into complex data structures, algorithmic paradigms, and essential computer science subjects required for online assessments (OAs) and technical interviews.*

- [ ] **Week 05: Trees & Binary Search Trees (BST)**
  - [ ] Tree traversals (Inorder, Preorder, Postorder, Level Order).
  - [ ] Standard Tree Problems (Height, Diameter, LCA).
  - [ ] BST operations: Insert, Delete, Search, and Validation.
- [ ] **Week 06: Heaps & Hashing**
  - [ ] Min Heap & Max Heap implementations.
  - [ ] Top K Elements / Merge K Sorted lists pattern.
  - [ ] Hash Maps and Hash Sets: Collision handling and standard problems.
- [ ] **Week 07: Graphs - Part I**
  - [ ] Graph representations (Adjacency Matrix & List).
  - [ ] Breadth-First Search (BFS) & Depth-First Search (DFS).
  - [ ] Cycle detection in Directed and Undirected graphs.
- [ ] **Week 08: Graphs - Part II & Greedy**
  - [ ] Topological Sort, Shortest Path algorithms (Dijkstra's).
  - [ ] Minimum Spanning Trees (Kruskal's & Prim's).
  - [ ] Greedy paradigm: Fractional Knapsack, Job Scheduling.
- [ ] **Week 09: Dynamic Programming (DP) - Part I**
  - [ ] Recursion to Memoization (Top-down) & Tabulation (Bottom-up).
  - [ ] 1D DP: Fibonacci, Climbing Stairs, House Robber.
  - [ ] 2D DP: Grid unique paths, Knapsack 0/1.
- [ ] **Week 10: Dynamic Programming (DP) - Part II**
  - [ ] Longest Common Subsequence (LCS) and Longest Increasing Subsequence (LIS) variations.
  - [ ] Matrix Chain Multiplication (MCM) & Partition DP.
- [ ] **Week 11: Core CS Subjects - Part I**
  - [ ] **Operating Systems (OS):** CPU Scheduling, Semaphores, Deadlocks, Memory Management (Paging/Virtual Memory).
  - [ ] **Database Management Systems (DBMS):** SQL Queries, Joins, Normalization, Transactions & ACID properties.
- [ ] **Week 12: Core CS Subjects - Part II**
  - [ ] **Computer Networks (CN):** OSI Model layers, TCP vs. UDP, IP addressing, DNS, HTTP/HTTPS.
  - [ ] **Object-Oriented Programming (OOP):** Encapsulation, Inheritance, Polymorphism, Abstraction, and OOP design questions.

## 🎯 Phase 3: Advanced Topics & Interview Prep (Weeks 13 - 16)
*Goal: Refine presentation skills, specialization projects, resume building, and participate in mock interviews.*

- [ ] **Week 13: System Design & Specializations**
  - [ ] High-Level Design (HLD) vs. Low-Level Design (LLD) introduction.
  - [ ] Project-specific reviews (Flutter, AI/ML, Web Dev).
- [ ] **Week 14: Resume Optimization & HR Prep**
  - [ ] STAR method for behavioral/project descriptions.
  - [ ] Resume review sessions with mentors.
  - [ ] Standard HR questions prep (Why this company?, Strengths & Weaknesses).
- [ ] **Week 15: Mock Interviews & Revision**
  - [ ] Peer-to-peer mock interviews (1-on-1 coding and behavioral).
  - [ ] Cheat sheet creation for rapid revision of DSA/Core CS.
- [ ] **Week 16: Final Preparation & D-Day Prep**
  - [ ] Solving company-specific past year questions.
  - [ ] Placement strategy seminar: "Cracking the Online Assessment & HR round".
